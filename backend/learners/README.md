# Learner profiles

This app stores individual learning preferences against the platform's existing shared user identity.

- A profile is optional; creating it does not create another login or account.
- An institute member may also have a learner profile and use the individual learning journey.
- No institute membership, seat, or subscription is created or changed here.
- Individual billing and entitlements belong to the future billing domain.
- Defaults are practice preferences, not exam rules or official qualification targets.

Run tests with:

```powershell
python manage.py test learners
```
